# tests/replay/

回放语料与回放证据的存放根（2026-11-25 经用户明确授权创建）。

## 与历史纪律项的边界

- 历史 AC（AC-B4-49 / 57 / 63、S-05）禁止的是 **`crates/application/tests/replay/`**：application 层的门控回放用例必须继续集中在 `crates/application/tests/gate_replay.rs` 与 `gate_replay_driver.rs`，不得拆成目录。该目录**至今仍不存在**，相关 AC 口径不变。
- 本目录位于**仓库根**，只放语料、期望输出与取证记录，不参与 `cargo test --workspace` 的 target 枚举，不新增 `NEW_TARGETS`，不新增 AC。

## 内容纪律

1. 不放真实会议录音、转写原文、姓名、公司名称等可识别信息；语料一律使用合成或脱敏文本。
2. 不放任何端点、Key、令牌、`providers.json` 实体；需要凭据的运行配置只写 `.tmp/`（已被 `.gitignore` 覆盖）。
3. 语料文件尽量小（单文件 < 256 KB）；大体积证据（截图、音频）放 `.tmp/`，此处只登记路径与结论。
4. 每个语料文件须能在本 README 的登记表里找到一行：用途、来源（合成/脱敏）、对应验收项。
